# Default Tokens

The `defaultTheme` provides a comprehensive set of pre-defined design tokens. All color values are sourced from the [Tailwind CSS v4 color palette](https://tailwindcss.com/docs/colors) and [shadcn/ui theming convention](https://ui.shadcn.com/docs/theming).

## Semantic Colors

Generated by `createThemeColors({ base: 'neutral', theme: 'neutral' })`. These follow the shadcn/ui naming convention.
